# Solar World Map

موقع ثابت (ملف واحد) يعرض خريطة تفاعلية بمساحة الألواح الشمسية المطلوبة لتشغيل العالم، باستخدام Leaflet.

## التشغيل

- افتح الملف `index.html` مباشرة في المتصفح، أو
- ارفعه على أي استضافة ثابتة (GitHub Pages أو Netlify أو غيرهما).

يحتاج المتصفح إلى اتصال بالإنترنت لتحميل Leaflet وبلاطات الخريطة من OpenStreetMap.
